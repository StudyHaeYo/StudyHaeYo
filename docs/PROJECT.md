# 프로젝트 소개

기준 시점: 2026-10-20 (`main` b387501 기준)

## 한 줄 정의

Notion처럼 학습 페이지를 자유롭게 만들고, 그 페이지에서 쌓인 학습 기록을 분석해 다음 학습(복습)으로 연결하는 개인 학습 관리 서비스. 단순한 Notion 복제가 아니라 "학습 데이터를 다시 다음 학습에 연결하는 것"이 핵심이다.

```
학습 계획 → 학습 페이지 → 실제 학습 → 학습 기록 → 분석 → 복습 → 다시 학습 페이지
```

## 각 개념의 역할

| 개념 | 역할 | 하지 않는 것 |
|---|---|---|
| 학습 페이지 | 무엇을 공부하는가. 본문과 종류(강의 · 오답 · 시험 · 빈 노트)를 가진다 | |
| 학습 기록 | 실제로 무엇을 했는가. 페이지 또는 과목에 붙는다(D-24) | 사이드바 트리의 노드나 별도 페이지 타입이 아니다 |
| 학습 계획 | 앞으로 무엇을 할 것인가 | |
| Home | 지금 무엇을 해야 하는가 | 전체 통계를 보여주지 않는다 |
| 학습 분석 | 지금까지의 상태가 어떤가 | |
| 복습 | 기존 페이지로 돌아가 다시 공부하는 행동 | 페이지 타입이 아니다 |
| AI | 열려 있는 페이지의 내용을 돕는 도구 | 페이지 타입이 아니다 |

## 팀과 도구

- 이재윤: 프론트엔드. v0로 UI 개발.
- 김준혁: 백엔드/DB/API/분석 로직.
- 코드: GitHub `StudyHaeYo/StudyHaeYo`. `main`이 공식 코드이고, 배포는 `main` → Vercel(studyhaeyo.vercel.app).

## 현재 구현 상태 (코드로 확인한 것)

**동작하고 Supabase에 저장된다**
- 계정: 이메일 회원가입(이메일 인증), 로그인, 로그아웃. 로그인하지 않으면 `/login`, `/signup`, `/auth/callback` 외의 화면은 로그인 화면으로 보낸다(`proxy.ts`)
- 학습 데이터: 로그인 사용자별로 저장된다(`workspace_nodes`, `study_records`, `learning_plans`). 신규 사용자는 빈 데이터로 시작하고, 홈에서 예시 데이터를 가져올 수 있다. 아래 기능이 여기에 해당한다. 첨부 파일은 Storage `attachments` 버킷에 저장한다
- 페이지/그룹 트리: 생성, 이름 변경, 복제, 삭제, 하위 그룹, 드래그 앤 드롭 이동, 노트 ⋯ 메뉴의 [옮기기](휴대폰에서도). 새 그룹은 과목이 기본, 사이드바 [+]는 지금 보고 있는 곳에 만든다. "+ 새 페이지"로 만든 뒤 제목도 내용도 없이 떠나면 그 페이지는 자동으로 지운다(그 탭에서 만든 페이지만)
- 모든 페이지가 블록 본문이다(D-23). "+ 새 페이지"는 빈 노트를 바로 열고, 본문이 비어 있으면 종류(강의 노트 · 오답 노트 · 시험 정리)를 모양 그림과 함께 고르거나 [AI로 채우기]로 시작한다. 고르지 않고 쓰면 빈 노트(D-26, D-30, D-33). 종류 칸은 사이트 DB에 `props` 칸이 생긴 뒤에 보인다. 모든 노트에 학습 기록 추가/수정/삭제
- 노트 화면(D-28, D-30): 제목 바로 아래 본문. 위쪽 바에 지금 상태(다시 볼 때예요 + [복습하기] / 기록이 아직 없어도 가릴 곳이 있으면 [복습해 보기] / 시험 D-n(준비 n/m은 범위 노트에 기록이 생긴 뒤) / 틀린 문제 + [다시 풀기]. 버튼은 노트 안 복습으로) · 종류 칩(눌러서 종류 바꾸기) · 타이머. 종류별 값은 본문 맨 위(시험일 · 범위 / 문제 출처 / 강의 자료 · 주차). 강의 자료는 [강의 PDF 올리기]로도 넣고(휴대폰에서도), 처음 올린 PDF가 바로 강의 자료가 된다. 템플릿 소제목 아래 빈 줄에는 어디에 쓰는지 연한 안내글이 보인다. 위쪽 바 [기록]은 그 노트의 기록 창(이해도 변화 · 총 시간 · 다음 복습 한 줄, 마지막 기록 한 줄, [+ 기록 남기기], 학습 기록에서 모두 보기), 시험 정리는 [범위 기록](범위 노트 기록, 읽기만). 노트 끝은 들어간 곳(시험 범위 · 계획)이 있을 때만(D-36, D-37). 태그는 화면에 없다. 사이드바 노트 줄에 종류 아이콘과 복습 점
- 학습 기록 남기기(사이드바, 휴대폰 상단 [+ 기록], 학습 기록 화면, 과목 화면, 노트, AI 채점): 무엇을 했나요 → 날짜 · 시간 → 이해도(말로) → 어디에(노트 · 과목 · 연결 안 함, 선택, 노트 안에서 열면 묻지 않음). [헷갈린 점을 노트에 추가] · [내일 할 일에 추가](D-24, D-28, D-30). 저장 전에 어디에 남고 다음 복습이 언제인지 보여준다. 자주 남긴 기록으로 한 번에 채운다. **노트 없는 기록(과목 · 과목 없음)은 `20261024_subject_records.sql` 실행 후에 고를 수 있고, 그 전에는 노트만 고른다**
- 학습 기록 화면(`/records`): 모든 기록을 날짜별로(그날 합계), 과목 · 과목 없음으로 거르기, 노트로 거르기(노트의 [기록] · 시험 정리의 [범위 기록]에서 열면), 검색, 고치기 · 삭제 · 노트에 연결, 노트 없는 기록으로 새 오답 노트 · 빈 노트 만들기
- 타이머 요약: 노트별 시간과 앱 밖에서 공부한 시간을 이해도만 골라 한 번에 기록. 진행 중인 계획이 얼마나 오르는지 보여준다(앱 밖 시간 줄은 SQL 실행 후)
- 과목 화면의 "학습 기록": 그 과목의 모든 기록(노트 기록 + 과목 기록)을 최신순으로, 학습 기록 화면과 같은 줄 모양
- 홈 "시작하기" 3줄: 페이지와 기록이 하나도 없을 때만
- 핵심 개념 · 헷갈린 점 블록
- 복습(D-34, 노트 안에서, 정해진 틀 없이): 노트가 쓴 모양 그대로 열리고 소제목 아래 글 · 토글 안쪽 · 핵심 개념의 뜻 · 오답 노트의 틀린 문제가 회색 줄로 가려진다. 그런 것이 없는 줄글 노트는 문단마다 첫 단어만 남는다. 떠올려 보고 펼친 뒤 알았음 · 헷갈림 · 몰랐음(문제는 맞힘 · 틀림)을 고르고 [복습 마치기]로 기록 하나. 마치면 제목 아래에 한 줄로 이해도 변화 · 다음 복습일 · [다음 노트]. 떠올릴 것이 없는 노트는 다시 읽고 이해도를 직접 고른다. 홈의 복습 목록, 노트 위쪽 바, 시험 범위에서 연다
- 오답 노트(D-35, 채점된 시험지): 문제마다 번호와 채점 표시(맞힘 동그라미 · 틀림 빗금), 펼치면 내 답 한 줄 · 정답과 풀이 · 틀린 이유(선택, 여러 개). 위쪽 줄에 틀린 문제 수와 이유별 수, 마지막 문제 아래 [문제 추가]. 다시 풀기는 틀린 문제만, 내 답은 보이고 정답 · 풀이만 가려진다. 맞힌 문제는 접혀 흐리게. 시작 칸은 빈 문제 하나
- 강의 노트(D-35, 코넬 노트): 줄마다 왼쪽 여백에 단서(질문이나 키워드)를 단다. 화면에서는 "질문"이라고 부른다. 마우스를 올리면 "+ 질문", 여백이 좁으면(PDF · AI 창을 열었거나 작은 화면, 휴대폰) 줄 위로 오고 블록 메뉴 [질문 달기]로 단다. 시작 칸은 필기 한 줄 · 구분선 · 요약 줄. 복습은 단서 단 줄만 가리고 단서를 보며 떠올린다
- 시험 정리(D-35, 범위표): 맨 위에 시험일 일력 · D-day · 요일과 상태별 수, [시험일 바꾸기]. 범위 노트마다 상태 글자(다시 확인 · 미확인 · 일부 확인 · 확인됨, 확인이 필요한 것부터)와 [복습하기] 또는 다음 복습일(시험 전날까지 당긴다). 노트 넣기 · 빼기. 그 아래 "시험 전에 다시 볼 것": 범위 노트의 해결 안 한 헷갈린 점(여기서 해결 표시 · 되돌리기), 아직 틀린 문제, 최근 기록의 어려웠던 점을 노트별로 모으고, 누르면 노트의 그 줄로 간다. 시작 칸은 "시험 당일 챙길 것"(체크 목록). 시험 정리는 자기 복습일이 없다(D-36)
- 본문 첨부(이미지, PDF, 기타 파일)와 그림 블록(펜, 형광펜, 지우개)

- 본문 편집: 줄 맨 앞에서 `/`로 블록 메뉴(제목, 목록, 번호 목록, 체크 목록, 토글, 인용, 콜아웃, 구분선, 페이지 링크, 코드, 그림, 파일 첨부). 노션식 단축 입력(`# `, `- `, `1. `, `[] `, `> ` 토글, `" ` 인용, `---` 구분선), 왼쪽 손잡이로 끌어서 순서 바꾸기·복제·삭제(휴대폰은 고른 줄에만 손잡이가 보이고 눌러서 메뉴로 옮긴다), `Alt+Shift+↑/↓`로 줄 옮기기
