# 프로젝트 소개

기준 시점: 2026-10-20 (`main` b387501 기준)

## 한 줄 정의

Notion처럼 학습 페이지를 자유롭게 만들고, 그 페이지에서 쌓인 학습 기록을 분석해 다음 학습(복습)으로 연결하는 개인 학습 관리 서비스. 단순한 Notion 복제가 아니라 "학습 데이터를 다시 다음 학습에 연결하는 것"이 핵심이다.

```
학습 계획 → 학습 페이지 → 실제 학습 → 학습 기록 → 분석 → 복습 → 다시 학습 페이지
```

## 각 개념의 역할

| 개념 | 역할 | 하지 않는 것 |
|---|---|---|
| 학습 페이지 | 무엇을 공부하는가. 본문과 속성을 가진다 | |
| 학습 기록 | 실제로 무엇을 했는가. 페이지 또는 과목에 붙는다(D-24) | 사이드바 트리의 노드나 별도 페이지 타입이 아니다 |
| 학습 계획 | 앞으로 무엇을 할 것인가 | |
| Home | 지금 무엇을 해야 하는가 | 전체 통계를 보여주지 않는다 |
| 학습 분석 | 지금까지의 상태가 어떤가 | |
| 복습 | 기존 페이지로 돌아가 다시 공부하는 행동 | 페이지 타입이 아니다 |
| AI | 열려 있는 페이지의 내용을 돕는 도구 | 페이지 타입이 아니다 |

## 팀과 도구

- 이재윤: 프론트엔드. v0로 UI 개발.
- 김준혁: 백엔드/DB/API/분석 로직.
- 코드: GitHub `StudyHaeYo/StudyHaeYo`. `main`이 공식 코드이고, 배포는 `main` → Vercel(studyhaeyo.vercel.app).
- 스택: Next.js(App Router), TypeScript, Tailwind, shadcn/ui, lucide-react.
- 협업: `main`에 직접 작업하지 않는다. 기능별 브랜치 → PR → 리뷰 → merge. v0는 `v0/...` 브랜치에 올리고 Publish로 main에 바로 반영하지 않는다(D-17). merge 버튼은 Vercel 프로젝트 주인인 이재윤이 누른다(D-19). Claude Code로도 작업한다.

## 현재 구현 상태 (코드로 확인한 것)

**동작하고 Supabase에 저장된다**
- 계정: 이메일 회원가입(이메일 인증), 로그인, 로그아웃. 로그인하지 않으면 `/login`, `/signup`, `/auth/callback` 외의 화면은 로그인 화면으로 보낸다(`proxy.ts`)
- 학습 데이터: 로그인 사용자별로 저장된다(`workspace_nodes`, `study_records`, `learning_plans`). 신규 사용자는 빈 데이터로 시작하고, 홈에서 예시 데이터를 가져올 수 있다. 아래 기능이 여기에 해당한다. 첨부 파일은 Storage `attachments` 버킷에 저장한다
- 페이지/그룹 트리: 생성, 이름 변경, 복제, 삭제, 하위 그룹, 드래그 앤 드롭 이동
- 모든 페이지가 블록 본문이고, 새 페이지 템플릿 5종(빈 페이지 · 학습 노트 · 강의 노트 · 오답 노트 · 시험 정리)으로 시작 블록을 고른다(D-23). 학습 기록 추가/수정/삭제
- 학습 기록 남기기(사이드바, 휴대폰 상단 [+ 기록], 과목 화면, 타이머 요약): **과목은 필수, 노트 연결은 선택**(D-24). 노트에 연결하면 그 노트의 복습일이 잡히고, 안 하면 과목의 학습 기록으로 남는다. 과목 고르는 칸에서 바로 새 과목을 만든다. 노트(AI 채점)에서 열면 그 노트로 고정된다. **과목 기록 저장은 `20261024_subject_records.sql` 실행 후에 열리고, 그 전에는 [+ 기록] 버튼들이 숨겨진다**(노트 아래 기록은 그대로)
- 타이머에서 공부할 과목을 고르면 진행 중 칩으로 보이고, 끝나면 노트 밖 시간을 그 과목 기록으로 남기라고 제안한다(SQL 실행 후)
- 과목 화면의 "학습 기록": 그 과목의 모든 기록(노트 기록 + 과목 기록)을 최신순으로. 노트 기록은 노트로 가고, 과목 기록은 고치거나 노트에 연결한다
- 홈 "시작하기" 3줄: 페이지와 기록이 하나도 없을 때만
- 핵심 개념 · 헷갈린 점 블록과 복습 모드(핵심 개념이 카드가 되고, 헷갈려요는 헷갈린 점 블록으로 추가)
- 본문 첨부(이미지, PDF, 기타 파일)와 그림 블록(펜, 형광펜, 지우개)
- PDF 보며 필기하기(쪽마다 펜, 형광펜, 지우개, 필기는 첨부 블록에 저장)
- 표 블록(`/표`: 머리글 행, Tab으로 칸 이동, 행·열 추가/삭제), 수식 블록(`/수식`: LaTeX → KaTeX)
- 인쇄 · PDF로 저장(페이지 ⋯ 메뉴): 제목과 본문만 인쇄. 홈 화면에 추가(PWA manifest, 남색 아이콘). 오프라인 동작(서비스 워커)은 없다
- 학습 계획 목표 시간(선택): 진행 막대가 목표 대비로 채워진다. **`20261025_plan_goal_minutes.sql` 실행 후에 입력 칸이 열린다**
- 노트 검색(사이드바 검색칸, ⌘K / Ctrl+K, 휴대폰 상단 아이콘): 제목, 본문(토글 내용 포함), 핵심 개념, 헷갈린 점, 학습 기록 메모. 초성 검색(ㅎㅅ → 해시테이블)은 제목만
- 본문 편집: 줄 맨 앞에서 `/`로 블록 메뉴(제목, 목록, 번호 목록, 체크 목록, 토글, 인용, 콜아웃, 구분선, 페이지 링크, 코드, 그림, 파일 첨부). 노션식 단축 입력(`# `, `- `, `1. `, `[] `, `> ` 토글, `" ` 인용, `---` 구분선), 왼쪽 손잡이로 끌어서 순서 바꾸기·복제·삭제, `Alt+Shift+↑/↓`로 줄 옮기기
- 뽀모도로 타이머(25분 집중 / 5분 휴식, 휴식 시간은 학습 시간에서 뺀다)
- 학습 계획 추가/삭제
- 과목 페이지(`/subject/[id]`): 요약, 페이지 목록, 이 과목의 학습 계획. 그룹은 폴더/과목을 고르고 바꿀 수 있다
- Home의 오늘의 체크리스트: 할 일 추가·체크·이름 바꾸기·삭제, 못 끝낸 일은 다음 날로 넘어온다(`todos` 테이블)
- Home의 "오늘 할 일"(복습할 노트, 진행 중인 계획의 기간 중 학습 시간, 체크리스트를 한 카드에)과 나의 학습 상태, 오늘의 기록, 이번 주 학습 통계, 학습 잔디(최근 12주)와 연속 학습일과 학습 분석의 모든 위젯(최근 8주 주별 추세와 한눈에 보기 포함): 실제 페이지와 학습 기록에서 계산한다(`lib/study-stats.ts`)

**동작하고 localStorage에 저장된다**
- 전역 학습 세션 타이머 (키: `studyhaeyo:study-session`)

**동작하지만 키가 있어야 한다**
- AI 학습 도우미(어느 페이지에서나 헤더 [AI]로 여는 오른쪽 패널): 페이지 내용으로 요약, 정리 노트, 확인 문제를 만들고 자유롭게 질문한다. 자료가 없으면 일반 지식으로 만들고 그렇다고 밝힌다. 답을 보내면 채점하고 점수를 학습 기록으로 남기거나 틀린 개념을 헷갈린 점 블록으로 넣는다. 답을 본문에 추가할 수 있다. 템플릿 "AI로 시작하기". 페이지에 저장된 PDF를 골라 같이 읽게 할 수 있다(최대 2개, 50쪽). Claude API를 쓰고, Vercel에 `ANTHROPIC_API_KEY`가 있어야 동작한다. 대화는 저장하지 않는다
